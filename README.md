# FirstClaudeCodeProject

A tiny starter project used to learn the Git/GitHub workflow with Claude Code.

## What's here

- [`greet.py`](greet.py) — a small `greet(name)` helper function.
- [`test_greet.py`](test_greet.py) — a couple of basic tests for it.

## Running the tests

```bash
python -m pytest test_greet.py
```
